# Simple Pie Chart Timer for Exams
## Motivation
This timer was created for my English teacher to better time the sections of the Czech Maturita oral exam. That is why this version of the timer has the branding of this specific high school.

## How to use
The timer is client only so you can simply download the repo and open index.html in your browser.

It is also hosted [here](https://lovec741.github.io/maturita-timer/) on github.
